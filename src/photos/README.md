# 📸 Drop your photos here!

Place any `.jpg`, `.jpeg`, `.png`, `.webp`, or `.gif` image files in this folder.

They will **automatically appear** as polaroid cards in the Memory Scrapbook page — no code changes needed!

### Tips
- Works with any common image format: JPG, PNG, WEBP, GIF
- Any number of photos you add will auto-fill the grid
- Delete or add photos freely — the page updates on next save/reload
